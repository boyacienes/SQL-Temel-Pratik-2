# SQL Temel Pratik 2

SQL öğrenme sürecimin ikinci pratik dosyası.

## Bu pratikte kullandığım konular
- COUNT
- AVG
- MAX
- AS
- UPDATE
- LIKE
- Alt sorgu (Subquery)
- Basit hesaplamalar

## İçerik
- 20 öğrenciden oluşan `ogrenciler` tablosu
- Öğrenci No, Ad, Soyad, TC Kimlik No, Kayıt Tarihi, Cinsiyet, Doğum Tarihi, Vize1, Vize2, Final notları
- Yukarıdaki konularla ilgili çeşitli sorgular

## Not
Tablodaki TC kimlik numaraları tamamen rastgele üretilmiş sahte verilerdir.
